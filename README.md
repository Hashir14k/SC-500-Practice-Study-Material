# SC-500 Practice Quiz

A practice quiz for the Microsoft **SC-500: Cloud and AI Security Engineer Associate** exam.

## About the project

- **`SC-500-Quiz.html`** — self-contained interactive quiz (works offline in any browser)
  - **Practice mode** — instant feedback, explanations where available
  - **Exam mode** — graded run, optional countdown timer (30/60/120 min), unanswered-question warning
  - Passing score: 92%
  - 54 graded questions + 2 study cards with reveal answers
  - 60 image-only questions cataloged on the start screen with PDF page references
  - Responsive layout (phone + desktop), dark mode, keyboard shortcuts (`A`–`E` answer, `←`/`→` navigate, `M` mark)
- **`SC-500 Dums.pdf`** — the original question material (277 pages, 117 questions)

## Repository contents

This repository holds the project README only. The quiz file and the question PDF are kept as local study copies and are not committed to this repository.

## Notes

- Questions **20** and **65** in the source PDF are scanned images with no extractable text, so they are not in the quiz.
- The source PDF contains two different questions both numbered **96** — both are included in the quiz, labeled `96a` and `96b`.
- Drag-drop / hotspot items whose answers exist only as screenshots are listed in the quiz's "not extractable" section with page numbers.
